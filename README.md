# AutoTrader Rosso

> This is an experiment. Don't take it seriously. I'm not giving financial advice to anyone. Use it at your own risk. The tool is driven by AI decisions, and AI can be wrong. Always double-check what it's doing.

This is my first attempt at building an autotrader, just **for fun**. I'm not trying to get rich off this.
It's **experimental and paper trading only**. The first build of the project was generated from AI prompts, following what's in [CONTRACT.md](CONTRACT.md).

Inspired by [Giuseppe Castagna's videos](https://www.youtube.com/@gcastagna).

I'll keep improving this tool over the next few weeks.

I'll also use this README as a personal diary. Once the project (maybe) starts to take shape, I'll write a proper README and archive this file.
